# AI-Powered Resume Generator

An AI-powered full-stack web application that generates ATS-friendly resumes using user-provided information.

## Features

* AI-generated resume content
* ATS-friendly formatting
* Dynamic resume preview
* Responsive React.js frontend
* Spring Boot REST APIs
* User-friendly interface

## Tech Stack

### Frontend

* React.js
* Vite
* JavaScript
* CSS

### Backend

* Java
* Spring Boot
* REST APIs
* Maven

## Architecture

Frontend (React.js)
↓
REST APIs
↓
Spring Boot Backend
↓
AI Resume Generation Service
